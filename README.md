# قافلة شِنقيط وخليَّة سنا: سباق الحلقات

## الملفات
| الملف | لمن |
| --- | --- |
| `index.html` | رابط الطالبات: الحكايات، وخريطة السباق، وقرص العسل. عرض فقط، بلا أي تعديل |
| `mushrifa.html` | رابط المشرفات والقائدة: يُفتح بالرمز |
| `assets/` | الخطوط والرسوم والبرمجة المشتركة |

ارفعي المجلد كاملًا كما هو. الصفحتان تعملان على GitHub Pages أو Vercel.

## البيانات
- تُحفظ في قاعدة بيانات المقرأة على «سوبابيس» (Supabase)، في جداول خاصة بالفعالية تبدأ أسماؤها بـ `ev_`.
- لا تعدِّل الفعالية أي جدول من جداول موقع المقرأة. تقرأ منها فقط قائمة الحلقات والمشرفات والطالبات عند الإنشاء، وعند ضغط «حدِّثي الحلقات» في لوحة القائدة.
- رابط الطالبات لا يرى إلا نتائج الأيام المعتمدة، بلا أسماء طالبات ولا أسماء مشرفات.
- كل كتابة تمرُّ عبر دوال في القاعدة تتحقَّق من الرمز. اليوم المعتمد لا تعدِّله إلا القائدة.

## طريقة الحساب
- **القافلة:** خمس خطوات في اليوم، والطريق ٢٥ خطوة:
  - الماء: الحضور.
  - سرعة الجمال: الحضور في الموعد.
  - الزاد: إتمام النصاب.
  - الأمان: المهمَّة الجماعية.
  - الدليلة والحارسة: المعلمة والمشرفة.

  موقع القافلة على الخريطة يتقدَّم محطة كل خمس خطوات، ومن تبلغ ٢٠ خطوة تصل شِنقيط.
- **الخليَّة:** ثلاث قطرات لكل طفلة في اليوم: الحضور في الوقت (ونصف قطرة للمتأخِّرة)، والنصاب، والتحدِّي. نسبة امتلاء الخليَّة هي مجموع عسل الطفلات وحدهن، ولا يؤثِّر فيها التزام المعلمة أو المشرفة.

## بطاقات التحضير والختام
- الصور داخل المجلد `assets/cards` (ثابتة في الكود، لا تُقرأ من القاعدة).
- تظهر للمشرفة داخل صفحة الحلقة لكل يوم: بطاقة التحضير وبطاقة الختام، مع زر «أرسليها» (يفتح المشاركة إلى الواتساب من الجوال) وزر «حمِّليها».
- مسارا «ألق» و«سراج»: بطاقات خليَّة سنا (من الأحد إلى الأربعاء). بقية المسارات: بطاقات قافلة شِنقيط (من الأحد إلى الخميس).
